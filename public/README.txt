**How to Use 使用指南 ** 

Create a Google Gemini API Key (Required): You can create your personal Gemini API Key by logging into Google AI Studio.
Due to the use of AI to analyse the user's answers, using a Default Gemini API Key from the free tier may face usage limits during analysis, leading to failure in generating the customised feedback and written reports. You can use a free tier Gemini API Key to explore the app. However, it is recommended that billing information is set up for "Pay per request" before creating a paid tier Gemini API Key to experience the full features of the app. You may also turn off the auto-reload function of your Google Cloud credits to ensure that no accidental overspending may incur. Please monitor your Google Cloud console. You are fully responsible for any charges on your account.
Average credit costs for completing ONE session including the interactive feedback with the written report is estimated around SGD $0.30 (as of July 2026).

Regarding your API Key: Your personal Gemini API Key will be stored locally in your browser cache. There is also a reset API Key button at the bottom of the main page of the App.
