Our AI simulated examiner view mimics exam conditions, helping your child build confidence and reduce actual exam-day anxiety. At the end of the session, you can download the audio recordings of your child's answers for thorough review.

A default female examiner view will be used. You can change your system Text-to-speech (TTS) voice setting if needed. If the microphone function is not used, you can also type in your child's answers for submission and analysis.

AI Teacher Lin will give customised feedback and provide model answers based on your child's performance, interacting in real time so that you can guide your child to immediately practise those newly learnt phrases. You will also be able to download the transcript of this feedback session for further practice.

Detailed Performance Assessment

How to Use
使用指南

    For the best experience, please use this web app on a computer.

  1. Create a Google Gemini API Key (Required): You can create your personal Gemini API Key by logging into Google AI Studio.
    Due to the use of AI to analyse the submitted answers, using a Default Gemini API Key from the free tier may face usage limits during analysis, leading to failure in generating the customised feedback and written reports. In addition, Google's Free Tier API may log and human-review prompts and responses for product improvement. To ensure complete privacy for your child's voice data and experience the full features of the app, it is strongly recommended to use a Paid Tier key (Pay-per-request) where Google does not retain or review your data. You may also turn off the auto-reload function of your Google Cloud credits to ensure that no accidental overspending may incur. Please monitor your Google Cloud console. You are fully responsible for any charges on your account. Please note that surges in API requests to Gemini may also cause server time-out.

    Average credit costs for completing ONE session including the interactive feedback with the written report is estimated around SGD $0.30 (as of July 2026).

    You can input a random number as your API Key if you only want to explore the user interface without accessing the AI features.

  2. Regarding your API Key: Your personal Gemini API Key will be stored locally in your browser cache.
    There is also a [Clear API Key] button at the footer of the App whenever you want to clear the stored API Key data. It is recommended to clear your API Key information from your browser when you have finished using the app, especially if you are using a shared device.
